# Cline prompts and notes

A small collection of prompts, project instructions and context templates for working with Cline. These are starting points to adapt to a specific codebase and task.

## Contents

- [Prompt examples](prompts/README.md) for understanding a project, implementing changes, debugging and review.
- [Setup notes](docs/setup-guide.md).
- [Starter project instructions](configs/starter-clinerules.md).
- [Project brief template](configs/memory-bank-template/project-brief.md).
- [Technical context template](configs/memory-bank-template/tech-stack.md).

## Use

Choose a prompt, replace the placeholders and add the relevant project context. Keep instructions focused on the current task, and check the resulting changes and behaviour.

For project rules, review the starter instructions before copying them. The context templates are ordinary Markdown files; they are useful only when kept accurate and provided to the assistant.

This collection is independent of the Cline project. For installation, supported providers and current features, use the [official Cline documentation](https://docs.cline.bot/).

Corrections and examples from practical use are welcome. Describe the problem the example addresses and any limits you encountered.
